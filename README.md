# MeerKAT-GRS-1758-258
Set of python codes/notebook used for the calculation associated with the relict jets in GRS 1758-258 as seen by MeerKAT

The full-analyysis is presented in:
A MeerKAT view of the parsec-scale jets in the black-hole X-ray binary GRS 1758-258. Mariani I., Motta S. E. , Atri P., Matthews, J. H., Fender R. P., Martí, J., Luque-Escamilla, P. L., Heywood, I. A&A, 704, A239 (2025)
https://doi.org/10.1051/0004-6361/202556290
